# UnitAtlas v0.1 Pilot Ready Core — Definition of Done

Эта матрица отделяет проверенный результат первого архитектурного PR от полного pilot-ready объёма.

| Требование | Состояние | Проверяемое свидетельство |
| --- | --- | --- |
| Domain/Application/Contracts/Infrastructure/API разделены | Готово в первом PR | `UnitAtlas.slnx`, project references, clean build |
| EF Core migrations вместо `EnsureCreated` | Готово в первом PR | `InitialArchitecture`, запуск на пустой PostgreSQL |
| Tenant-aware уникальность и составные FK | Готово в первом PR | migration constraints |
| Event order не откатывает Current State | Готово в первом PR | unit + HTTP integration tests |
| CI собирает образы и запускает тесты | Готово в первом PR | GitHub Actions run |
| Generic OIDC bearer validation, tenant context и роли | Готово во втором PR | membership/permission integration tests |
| Enforced tenant isolation: query filters + forced RLS | Готово во втором PR | negative cross-tenant tests и non-superuser DB check |
| Полная идемпотентность с request hash/conflict semantics | Готово в третьем PR | replay/conflict/concurrency tests |
| Production primitives: Site, Location, Lot, identifiers, audit, outbox | Готово в третьем PR | migration/backfill и RLS checks |
| Версионированный internal API и безопасный public API | Не начато | contract/security tests |
| Next.js BFF без прямого privileged browser→API доступа | Не начато | browser/network test |
| Rate limits, security headers, audit, OTel | Не начато | automated safeguards checks |
| Runbook, backup/restore rehearsal, release tag `v0.1.0` | Не начато | сохранённые команды и release evidence |

## Ограничение первого PR

Первый PR намеренно меняет только архитектурный каркас, миграции и тестовую инфраструктуру. OIDC, интеграция с 1С и новые UI-функции в него не входят: так изменение остаётся обозримым и обратимым.

## Проверка и rollback

Проверка: clean build, unit tests, чистая миграция PostgreSQL, HTTP smoke и delayed-event test. Rollback: сгенерировать down SQL `InitialArchitecture → 0`, проверить его только на одноразовой БД и откатить Git PR. Удалять существующий volume для проверки запрещено.
